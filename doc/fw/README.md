# Firmware Image Format Documentation

The `*.ksy` [Kaitai Struct][kaitai] files in this directory specify firmware image formats.

Firmware images can be parsed and inspected using the [Kaitai Web IDE][ide].
To this, follow the link to the IDE and upload both the `*.ksy` file and the firmware image file you want to parse with it.


## [asm\_fw.ksy](asm_fw.ksy)

A [Kaitai Struct][kaitai] definition for the ASMedia USB host controller firmware image format.


## [prom\_fw.ksy](prom_fw.ksy)

A [Kaitai Struct][kaitai] definition for the Promontory chipset firmware image format.


[ide]: https://ide.kaitai.io/
